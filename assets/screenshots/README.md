# Screenshots

Screenshots for the main [README](../../README.md). This folder is documentation only: it is not listed under `flutter: assets:` in `pubspec.yaml`, so nothing here is bundled into the app.

To publish a screenshot, add a PNG with the matching file name below, then replace its *Coming soon* placeholder in the README with the image.

| Screen | File |
|---|---|
| Home | `home.png` |
| Navigation | `navigation.png` |
| Group Ride | `group-ride.png` |
| Leaderboard | `leaderboard.png` |
| Ride Replay | `ride-replay.png` |
| Ride History | `ride-history.png` |
| Insights | `insights.png` |
| Fuel Stations | `fuel-stations.png` |
| Profile | `profile.png` |
| Share Card | `share-card.png` |

Guidelines:

- Portrait phone screenshots, PNG, about 1080 × 2340.
- Use test data. No real home addresses, names, emails or live locations.
- Keep each file under about 500 KB.
