## RideSync v1.0.0

The first public release of RideSync: a real-time ride companion for solo riders and groups.

**Download:** `RideSync-v1.0.0.apk` below (Android). See the [installation guide](https://github.com/SaiVarun-26/Ridesync#-download-ridesync).

### 🚀 New Features

- **Four ride types:** Solo Free Roam, Solo Guided, Group Free Roam and Group Guided.
- **Live group map** with every rider's position, colour and trail.
- **Guided rides** with destination search, route planning and turn-by-turn guidance.
- **Live Leaderboard** with rider ranking, live speed and gaps.
- **Ride Replay** on each rider's real GPS timeline.
- **Ride History** with rename and delete.
- **Ride Insights:** top speed, performance, timeline, standings, group moments and achievements.
- **Fuel station discovery** with company-coloured markers and a one-tap toggle.
- **Smart Auto End** with a 15-second confirmation countdown.
- **Pause and Resume** for breaks, without ending the ride.
- **Share cards** with the real map and route.

### ✨ Improvements

- **Every rider ends their own ride**, while the rest of the group keeps riding.
- **Clear End Ride and Pause buttons**, always in view.
- **Automatic ride names** from where the ride ended, always editable.
- **Safety tools** shown only in group rides.

### 🐛 Bug Fixes

- **Auto-ended rides** are now always saved to Ride History.
- **Fuel station markers** load reliably.
- **Group ride summaries** include every rider's statistics.
- **Replay keeps riders in sync** on one shared timeline.

### ⚡ Performance

- **Fuel stations** are cached on the device and loaded in the background.
- **Map markers** are drawn efficiently for smooth panning and zooming.
- **Ride saving** retries automatically, so a completed ride is never lost.

### 🔧 Technical Changes

- **Automated releases:** a version tag builds the APK and publishes it to GitHub Releases.
- **Continuous integration:** analysis and tests run on every push and pull request.
- **Release signing** is configured through repository secrets, and keys are never committed.

### 📲 Installing

1. Download `RideSync-v1.0.0.apk` from the assets below.
2. Open it on your Android phone and allow installing from this source if asked.
3. Grant location (including background) and notification permissions when RideSync asks.
