# Security Policy

## Supported versions

Security fixes are made for the latest release only.

| Version | Supported |
|---|---|
| Latest release | ✅ |
| Older releases | ❌ |

Always use the newest version from [GitHub Releases](https://github.com/SaiVarun-26/Ridesync/releases/latest).

## Reporting a vulnerability

**Please do not report security problems in public issues.**

Report them privately through GitHub's [private vulnerability reporting](https://github.com/SaiVarun-26/Ridesync/security/advisories/new). Include:

- What the problem is and its possible impact
- Steps to reproduce it
- The RideSync version and Android version
- Any suggested fix, if you have one

You can expect an acknowledgement within a few days. Once the problem is confirmed, a fix will be prepared and released, and you will be credited unless you prefer otherwise.

## Scope

In scope:

- The RideSync app code in this repository
- The Firebase security rules in `firebase/`

Out of scope:

- Third-party services RideSync uses (Firebase, OpenStreetMap services, Open-Meteo); please report those to their providers
- Problems that need a rooted or compromised device
